# Project instructions

- Keep work local unless the user authorizes publication or deployment.
- Before every image upload, resize the image for its actual display use, optimize the file size, and convert it to WebP. Check visual quality before uploading. This is an explicit user preference.
- Never commit storage credentials, tokens, or secrets. R2 API credentials belong only in local environment variables.
- Intended public asset domain: `https://cdn.adfirm.net`. Confirm the R2 bucket and verify the uploaded object before switching a website asset to its CDN URL.
